本机后台自动解锁

首次输入主密码授权此 Windows 用户。之后 Workbuddy 可按需隐藏启动服务，无需打开网页；本模式持续解锁，关闭网页不会退出。网页查看仍需密码。

启用后，在当前 Windows 用户登录时启动本地账本服务，无需打开网页。退出当前 Windows 会话或关机时服务结束。

授权凭据由 Windows DPAPI 保护，仅存本机。控制当前 Windows 用户的程序可能访问账本。点击锁定或修改密码会撤销授权；撤销后智能体访问立即停止。

基于 Bastide 的 Python 后端扩展，共用其账户、分类、交易模型与余额逻辑。个人模式使用独立的加密账本，不会修改原版账本。
