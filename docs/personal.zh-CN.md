# 本地账本：个人模式使用说明

这是针对 `软件实现.md` 最后一段需求，在 Bastide 源码内增加的个人模式。入口与原版 Flutter 应用分开，复用同一套账户、分类、交易模型、余额维护函数和 Alembic 迁移。原版没有被替换。

## 1. 启动与首次使用

在仓库根目录双击 **`启动个人账本.cmd`**。

本次开发已经在这台电脑准备好 Python 3.14 和后端依赖。启动器优先直接使用已准备的 `backend/.venv`；依赖未准备好时才使用 `uv` 安装。首次换电脑运行可能需要联网下载 Python 和依赖，准备好之后，记账与统计不需要联网。项目上一级的 `.tools/python/` 是这台电脑的解释器，不能在仍使用当前环境时删除；`.cache/` 是可删除的开发缓存。

也可在 PowerShell 运行：

```powershell
cd D:\VScode_TRAE\A_Bill\PersonalLedger
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start_personal.ps1
```

默认自动打开本机地址 `http://127.0.0.1:8899`。这是在你的电脑上运行的界面，不是云端网站。关闭最后一个账本标签页约 5 秒后，后端正常退出并释放账本文件锁；双击启动时打开的终端也随启动脚本结束而关闭。刷新页面在此宽限期内重连，不会退出；其他账本标签页仍打开、页面在后台或账本已锁定时，也不会退出。仍可在终端按 `Ctrl+C` 手动停止；15 分钟无界面操作自动锁定的规则保留。

若从 VS Code、PowerShell 等已有终端启动，自动退出会结束账本进程并返回命令提示符，不会关闭你原来的终端或编辑器。如果启动后 2 分钟内没有任何账本页面连接，服务也会退出；浏览器未自动打开时，请在此时间内手动访问上述地址。

若希望关闭网页后 Workbuddy 仍可连接本地服务，可使用后台运行模式（账本仍需解锁，且保留自动锁定）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start_personal.ps1 -KeepRunning
```

后台模式需要手动按 `Ctrl+C` 退出。命令行 `--no-browser` / 启动脚本 `-NoBrowser` 默认也保持后台运行，便于测试和手动打开页面；Python CLI 可显式使用 `--exit-on-close` 覆盖。正常退出只保留已经点击保存并成功写入的记录，尚未提交的表单不会自动保存。

如果端口被占用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start_personal.ps1 -Port 8900
```

首次使用设置至少 10 个字符的主密码，并**离线保存只显示一次的恢复密钥**。没有预设密码，也不需要注册邮箱或云端账户。忘记主密码和恢复密钥后，无法找回加密数据。

## 2. 已实现的功能

| 模块 | 可以做什么 |
| --- | --- |
| 财务总览 | 本月收支、区间结余、账户资产、六个月趋势、分类分布、最近交易 |
| 交易记录 | 新增/修改/删除收入、支出、转账；实际日期、账户、分类、商家、备注；筛选和分页 |
| 我的账户 | 现金、微信、支付宝、银行卡；新增账户、修改名称/期初余额、归档 |
| 分类与规则 | 两级分类；新增/重命名/移动/删除空分类；关键词规则和商家别名 |
| 批量整理 | 原分类 → 目标分类的笔数预览、确认、冲突检查、撤销 |
| 数据分析 | 月度、年度、分类排名、商家排名、同比；父分类包含子分类 |
| 账单导入 | 微信、支付宝、MMEX 兼容 CSV、通用 CSV；本地预览、跳过原因、去重、确认、整批撤销 |
| 安全 | 加密账本、密码/恢复密钥解锁、自动锁定、修改密码、加密备份与恢复 |
| Agent | 本机 HTTP API + 官方 MCP SDK 的 stdio 工具；写入授权和明细读取授权分开 |

财务金额在数据库与 API 中都使用**整数分**。例如 `1250` 是 `12.50 元`；不要将 `12.50` 作为 API 金额传入。UI 输入使用元。

转账生成两条配对流水：转出账户扣款、转入账户入账，合计资产不变。编辑/删除/撤销会同时处理两端。转账不会被统计成收入或支出。

每次手工或 Agent 写入都带 `request_id`。同一请求重试返回同一结果，不会重复记账；不同内容不能重复使用同一个 `request_id`。编辑接口返回修改后的账目 ID，后续操作请使用返回值。

分类批量整理仅处理**直接归入所选分类**的账目，不隐式改变子分类。预览 30 分钟过期；预览后相关账目发生变化会拒绝提交。撤销同样检查后续修改，必要时先撤销后面的操作。

## 3. Workbuddy 接入

这里采用文档最后需求的保守默认：**Workbuddy 在这台电脑上调用本机 MCP 工具**。不开放公网，不配置反向代理或远程数据库。

1. 启动并解锁本地账本。
2. 打开左侧“安全与智能体”。
3. 保留“允许新增、修改交易与批量分类”；如只想分析，可取消它。
4. 默认不要勾选“额外允许读取逐笔账目”。
5. 点击“生成 / 轮换 MCP 令牌”，复制页面生成的完整 `mcpServers` 配置，加入 Workbuddy 的自定义 MCP 配置。
6. 重启/重新连接该 MCP 服务。不同 Workbuddy 版本的配置入口可能不同，这里提供通用 stdio MCP 配置，不修改其未知的安装设置。

配置含本机 Python 的绝对路径、`PYTHONPATH`、本机 API 地址和 Bearer 令牌，不包含账本密码。换电脑、换路径或换端口后，请重新生成配置。**令牌配置只保存在本机，不上传 GitHub。** 轮换令牌会使旧令牌立即失效。

可用工具：

| 工具 | 用途 |
| --- | --- |
| `list_accounts_and_categories` | 取得账户和分类 ID，不读账目明细 |
| `create_transaction` | 新增收入/支出或配对转账 |
| `update_transaction` | 完整更新指定账目，可在界面撤销 |
| `run_analysis` | 本地 Python 计算报表，仅返回汇总 |
| `preview_category_change` | 返回分类迁移影响笔数和预览 ID |
| `commit_category_change` | 用户确认后执行预览 |
| `query_transactions` | 仅在明确授予 `details` 权限后才能读取逐笔账目 |

可以这样使用：

> 昨天在附近早餐店花了 12.50 元，记到微信账户，分类为餐饮/早餐。
>
> 用本地 Python 统计今年每个月的支出，只给我汇总结果，不读取逐笔账单。
>
> 先预览一下，把“其他支出”的账目归到“生活/日用品”会影响几笔，等我确认再修改。

普通模式下，Agent 不负责解锁账本，15 分钟无界面操作会自动锁定。启用第13节的本机后台授权后，服务可自动解锁并持续供 Agent 使用；网页本身仍需密码登录。主动锁定会撤销本机后台授权，所有 Agent 工具随即失去数据库访问能力。

**隐私边界：**软件不会主动调用任何大模型，也不会把数据库文件上传。统计摘要经 Workbuddy 展示时，摘要仍可能进入它所使用的模型上下文；如果允许逐笔读取，则相应明细也可能进入上下文。新增记账时你发给 Workbuddy 的文字本身仍属于 Workbuddy 的输入。这些与“本地 Python 计算”是不同环节。

## 4. 自己用 Python 做分析

可用报表名：`summary`、`monthly`、`annual`、`category_ranking`、`merchant_ranking`、`year_over_year`。

接口 `GET /api/agent/analysis` 只执行代码中允许的本地 Python 报表。没有任意 SQL、`eval`、Python 代码执行或上传脚本接口。

仓库自带命令行脚本 `tools/analyze_personal.py`。在本机进程环境中设置 `BASTIDE_PERSONAL_TOKEN` 后，可这样运行：

```powershell
.\backend\.venv\Scripts\python.exe .\tools\analyze_personal.py --report monthly --start 2026-01-01 --end 2026-12-31
```

不要把真实令牌硬编码到脚本。换端口时另设 `BASTIDE_PERSONAL_URL`。

增加自定义统计时，可在 `backend/app/features/personal/analysis.py` 增加可信的本地报表函数，并加入报表白名单；查询放在 `repository.py`，增加对应测试。这样只有汇总结果从接口返回。明文 JSON 导出仅用于你明确选择的离线分析/迁出，不是常规 Agent 分析方式。

## 5. 微信、支付宝和 MMEX 账单导入

先在官方支付工具导出个人账单，选择 **CSV**。本版本不读取微信聊天、不抓取通知、不要求支付密码，也不声称已接入付款实时回调。

选择正确的本地账户再上传文件。支持 UTF-8（可有 BOM）和 GB18030，最大 2 MiB，一次最多 5000 行。提供原交易单号时按“账户＋来源＋交易单号”去重；没有单号时使用账户、日期、整数金额和商家描述的规范化摘要。同一天同商家同金额的无单号记录可能被视为重复，应检查预览并按需手工补录。

退款、失败、关闭、转账和“不计收支”不自动记入收支，预览会给出跳过原因，请人工核对。退款不能简单地当作当期收入处理后声称准确还原历史支出。尚未分类的成功交易可以确认导入，之后统一整理。

MMEX 不与此账本共用数据库。可从 MMEX 导出 CSV，字段使用 `Date,Type,Amount,Payee,Notes,Category`，日期设为 `YYYY-MM-DD`，类型为 `Withdrawal` / `Deposit`。其他语言或自定义列顺序不影响按列名识别，但字段名称不同需调整为模板名称。不会直接打开 MMEX `.mmb` / `.emb` 加密数据库。

通用模板：

```csv
date,kind,amount,merchant,note,category,external_id
2026-11-17,expense,12.50,虚构早餐店,早餐,早餐,example-001
2026-11-17,income,8000.00,虚构公司,工资,工资,example-002
```

以上均为虚构示例。模板的 `amount` 单位为元，`kind` 用 `expense` / `income`。软件界面可下载只含表头的空模板。

## 6. 加密、备份与迁移

活动账本位置可独立于源码目录配置：复制仓库内 `personal.local.example.json` 为 **`personal.local.json`**，把 `vault_path` 改成你的同步目录中 `ledger.bfin` 的绝对路径。此本机配置已加入 `.gitignore`，不会随源码上传。启动终端会显示实际账本路径。原版 Bastide 的 `bastide.db` 不会自动导入或改写。

路径优先级为：命令行 `--vault`（或启动脚本 `-Vault`）→ 环境变量 `BASTIDE_PERSONAL_VAULT` → `personal.local.json` → 兼容旧版本的 `.personal-data/ledger.bfin`。配置错误会报错，不会悄悄改用另一个空账本。旧默认目录仍有账本且新配置指向其他位置时，会要求先明确迁移，避免丢失原账本入口。

若已经有账本，先停止软件并保存加密备份，再将 `ledger.bfin` 移到新目录，更新配置并解锁核对。不要复制明文数据库，也不要在两处同时维护活动账本。本次目录调整时没有正式账本需要迁移，首次建账会直接写入已配置的位置。

实际采用的方案是**加密容器＋内存 SQLite**，不是 SQLCipher：

- 用操作系统安全随机数生成 256 位数据库密钥。
- 主密码通过 Argon2id 派生包装密钥（64 MiB 内存、3 次迭代、4 路并行、随机 16 字节盐）。
- 使用 `cryptography` 的 AES-256-GCM 包装数据库密钥并加密完整 SQLite 镜像。
- 另有独立随机 256 位恢复密钥的包装槽；不保存明文密码/恢复密钥。
- SQLite 只在内存中解密，临时表也限制在内存中。
- 每次成功写入：数据库提交 → 序列化 → 随机 nonce 加密 → 同目录临时**密文** → fsync → 原子替换。写盘失败时内存数据也回滚。
- 操作系统文件锁阻止两个进程同时打开同一个活动账本。
- 令牌在加密账本里仅保存哈希。明文令牌只在生成配置时显示。

因为是整份内存账本和整份加密提交，个人模式目前限制账本文件最大 128 MiB；它适合个人记账，不适合作为高并发、大规模财务服务器。

在“安全与智能体”下载 `.bfin` 备份，再把备份放入坚果云。也可以把活动账本配置到已由坚果云同步的目录，但**只能一台电脑使用完、退出并完成同步，再换另一台电脑打开**。同步前后确认文件已完整下载到本地，不要只保留云端占位符。软件不能自动替你设置坚果云目录。

本地文件锁不能跨电脑工作。软件在写入前检测磁盘文件是否被外部替换/删除，发现变化会拒绝覆盖并回滚本次操作；此检查不是分布式锁，不能消除同步检查与写入间的竞态，仍不支持两台电脑同时写入。发现冲突文件时先保留所有版本，停止同步写入，核对恢复，不要直接覆盖。

换电脑后可直接配置完整下载的加密文件，或从登录页面选择“从加密备份恢复账本”，输入备份时的主密码或恢复密钥。恢复前会保留 `ledger.before-restore.bfin`；该固定名称仅保留最近一次恢复前的副本，长期版本请自己留存。

修改主密码只影响当前活动文件，**不会修改之前下载的备份密码**。不要把恢复密钥与加密备份放在同一个同步目录。

备份是完整快照，也包含当时的 Agent 令牌哈希和权限。恢复旧备份后，先在“安全与智能体”重新生成令牌并更新 Workbuddy 配置，避免继续使用备份时的旧授权。

加密保护静态文件，不能防御已控制电脑的恶意程序、进程内存读取、系统交换文件或内存转储。需要这方面保护时配合系统磁盘加密。不要在软件解锁时让其他人操作同一系统账户。此版本没有 Windows Credential Manager 自动解锁或独立恢复密钥轮换功能。

## 10. 家庭往来与个人开销

父母转入：选择收入，分类“父母转入”。转给父母：选择支出，分类“家庭支持 / 给父母”。界面的“转账”只用于自己的账户互转，不用于与父母之间的收支。

总览同时显示总支出和个人开销：总支出包含给父母的钱；个人开销排除它。实际余额和总口径结余始终包含所有收支。报表页可切换“全部支出 / 个人开销”，月度、年度、分类、商家排行及同比按所选口径计算。个人口径中的收入仍保留父母转入；收入减个人开销的差额不等于实际现金结余。

“分类与规则”中编辑支出分类，可选择是否计入个人开销。父分类被排除时，其所有子分类也被排除。该设置按分类 ID 保存，改名不丢失。修改设置会追溯影响该分类的历史统计，不改变原交易和余额。已有账目不会自动根据备注猜测是否属于父母往来，请手工重新分类或预览批量整理后确认。

升级后重启服务并解锁，会补齐上述分类；不需要迁移数据库结构。Workbuddy 重新连接 MCP 后先获取账户分类目录。可以说：“给父母转了500元，记支出，归入家庭支持/给父母”，或“父母转入1000元，记收入”。不要把这些记录写成 transfer。

Workbuddy 分析个人开销时调用 run_analysis，传 expense_scope="personal"；全部支出用 "all"。本地命令行脚本也支持 --expense-scope personal。普通分析 API 同样接受 expense_scope 查询参数。不要向智能体提供主密码或恢复密钥。

## 11. 2026-07-15 起累计、基金账户与每周持仓

财务总览右上角新增“统计来源”：按月统计 / 2026-07-15 起累计（含当天）。累计口径到当前日期，包含封存账户的历史收入、总支出和个人开销，排除自有账户间转账、基金买入赎回和市值变动。资产卡片显示当前启用账户的资产，不代表历史时点资产。

升级后重启并解锁，会幂等补齐四个账户：支付宝债券账户、支付宝股票型基金零花钱账户、微信理财通账户、微信零花钱账户。已有同名账户不会重复创建或取消归档。旧账户不改动。初始现金和基金金额均不预设真实数值。

在“我的账户 → 管理”填写期初现金、账户用途和每月零花钱额度（0 表示尚未设置）。然后在“财务总览 → 账户详情分析”选择账户：

1. 已经持有的基金：点击“登记期初基金”，输入基金名、基准日期和当时的金额。这不是收入，也不从现金再扣款。期初现金中不要再包含这些基金，否则会重复计算总资产。
2. 新买基金：先建立金额为 0 的基金，再点击“买入”，填写真实买入金额。现金减少、基金金额增加，不计消费。
3. 赎回基金：先确认赎回前最新市值，再记录实际赎回金额。基金减少、现金增加，不计日常收入。赎回金额高于已记录市值时需要先更新市值。
4. 每周点击“记录本周基金金额”，逐项填全部基金新的总金额，不需要提供涨幅百分比。若期间有买入或赎回，先登记它们。系统以调整过本金的上次金额为基准，计算本次估值变化；若没有记录期间的买卖，系统无法区分本金和收益。
5. 输入错误：在持仓变化记录中，从每只基金最后一条有效记录起撤销，再重新填写。普通交易页不能直接修改基金买卖的关联现金流水。期初基金登记尚无任何变动历史时，可通过接口删除后重建；已有历史的基金保留记录，清仓用赎回登记。

账户总资产 = 当前现金 + 各基金最新记录金额。不同基金的最后记录日期单独显示；未更新的基金不会自动获取行情。估值变化只反映你提供的金额变化，不是承诺收益，不提供投资建议。本版本不计算收益百分比、份额、净值或精细税费；费用若影响持仓，请按真实现金和市值核对，不把不明资金差异直接当收益。债券用途账户不接受普通消费支出，买卖使用账户详情，自有账户间划转使用转账。

两个零花钱账户可以设置每月额度；建议结余 = 每月额度 − 本月个人开销 − 当月已转存到储蓄账户的金额，最低为0；建议实际转存还受可用现金限制。给父母等非个人支出不计入这个额度消耗，但仍减少真实现金。未设额度时不推算结余。

“零花钱结余转存”由你核对金额并完成真实转账后确认记账，默认目标为理财通/储蓄用途账户。软件不会自动卖出基金、操作支付宝/微信、按月后台转账。转存是两端配对流水，不计收入支出；撤销仍在操作历史进行。归档账户可看历史，但不能新增持仓、买卖或周度记录。

### Workbuddy 用法

重启账本并重新连接 MCP，以发现新增工具：finance_since_start、get_account_portfolio、add_fund_holding、record_weekly_valuations、record_fund_trade、transfer_allowance_remainder。原有记账和分析工具保留。令牌通常无需轮换；新增写入仍受 write 权限限制。账户持仓接口返回现金、每基金汇总金额与预算建议，不返回逐笔现金流水；这些汇总信息会进入调用它的智能体上下文。

示例（金额为虚构）：

- “统计2026年7月15日以来的全部收入、支出和个人开销。”
- “我的债券账户现金为600元，已有虚构基金甲400元，分别设置期初现金和期初基金，别把基金金额重复算进现金。”（账户期初现金请在界面管理中设置；MCP 不直接提供改期初现金工具。）
- “本周虚构基金甲总金额变为408元，没有买入赎回，请更新周度金额，不填写百分比。”
- “先显示本月微信零花钱结余建议；等我确认已经转账后，再登记转入理财通。”

所有 API 金额仍为整数分。record_weekly_valuations 需要先 get_account_portfolio 获取基金 ID，提交该账户全部基金的 holding_id 与 value_minor。写入使用唯一 request_id，网络重试保持同一个 ID。账本仍由你在本机解锁，不要把密码和恢复密钥交给智能体。

## 12. 账户排序与归档分组

“我的账户”分为“使用中”和默认收起的“已归档账户”分组，标题显示账户数量。每个账户右侧的“上移”“下移”可调整其在当前分组内的顺序；第一项不能再上移，最后一项不能再下移。顺序保存在原加密账本中，刷新、锁定再解锁或重启后仍保留，并应用于使用相同账户目录的选择列表。新建账户默认追加到使用中分组的末尾。

归档账户：点击“管理”，勾选“归档账户”，保存后自动移入下方分组。恢复账户：展开“已归档账户”，点击该账户的“管理”，取消归档并保存。分组是软件内的显示整理，不会创建额外的账本文件或移动数据库；余额、基金持仓、历史交易及累计收支统计不因调整顺序而改变。归档账户保留历史，但不计入当前启用账户总资产，且不能新增账目或基金记录。

升级后重启账本并刷新页面即可使用，无需重建数据库或重新配置 Workbuddy。账户顺序调整仅开放给本机账本界面，不新增智能体写入权限。

## 13. 本机首次授权，Workbuddy 按需隐藏启动

此功能默认关闭，需要你在自己的电脑上完成一次主密码授权。代码更新不会替你启用真实账本的授权，也不会读取主密码。

1. 停止旧版账本服务，双击“启动个人账本.cmd”，输入主密码解锁。
2. 打开“安全与智能体”，在“本机后台自动解锁”中点击“授权本机后台访问”，再次输入主密码确认，直到显示“已授权”。
3. 若 Workbuddy 尚未接入，点击“生成 / 轮换 MCP 令牌”，将完整配置保存在 Workbuddy 的本机 MCP 配置中。新配置会包含明确的账本路径，避免路径选择错误；轮换令牌会让旧配置失效。已有配置若指向本项目的 app.personal_mcp，可先保留并重新连接 MCP。
4. 关闭网页即可继续通过 Workbuddy 记账或分析。服务尚未运行时，MCP 会在首次工具调用时启动隐藏后台服务；这也适用于重启电脑并登录当前 Windows 用户之后，不需要先启动网页。没有注册开机启动项，服务按需启动。

首次授权所在的当前进程若原本带有终端，终端不会自动消失；可停止旧进程后直接在 Workbuddy 调用工具，它会隐藏启动服务。以后双击启动器时，已授权账本会隐藏运行；服务已在运行时只打开网页，仍需输入密码查看账目。不要点击“锁定”作为关闭网页的替代，因为锁定会撤销本机授权。

本机授权凭据使用当前 Windows 用户的 DPAPI 保护，保存于 `%LOCALAPPDATA%\BastidePersonal\device\<账本绝对路径摘要>.dpapi`。此文件不放在源码目录、MCP 配置或坚果云账本目录；不保存明文主密码，不给智能体传递主密码或恢复密钥。数据库格式和原有密码 / 恢复密钥解锁方式保持不变。自动解锁不等于网页免密码：服务启动不会颁发网页会话，逐笔账目权限仍由 MCP 令牌控制。

**信任范围：**启用期间，后台进程会持续持有已解锁账本，不再因15分钟无网页操作或关闭网页而退出。能控制当前 Windows 用户会话的程序可能利用该授权访问账本；设备失窃、Windows 用户被控制等情况不能仅靠数据库加密防护。只把加密账本同步给别人而不提供主密码、恢复密钥或本机解锁能力，并不会因此赋予别人自动解锁能力。本机凭据文件不应同步或复制给别人。

暂停 / 撤销：打开网页、输入密码，在“安全与智能体”点击“撤销本机授权并锁定”；Agent 会立即失去访问能力。若还要结束隐藏服务，使用“撤销授权并退出服务”。顶部“锁定”同样撤销本机授权；修改主密码也会撤销授权，之后需要重新授权。正常关闭服务或重启电脑不会撤销已保存的授权。移动账本到不同路径、换电脑 / Windows 用户或授权文件损坏后，需要在界面重新授权。

**坚果云多设备使用：**后台服务会持有活动账本的本机文件锁，即使网页关闭也仍在使用账本。切换到另一台电脑前，必须“撤销授权并退出服务”，等待同步完成后再在另一台打开；不要让多台已授权服务同时写同一份同步账本。检测到同步文件被替换后仍会拒绝覆盖，请先停止服务并检查同步冲突。

验证：完整后端1461项通过（包括7项 Windows 原生 DPAPI / 本机授权测试），原有16项浏览器流程通过；新增真实 Edge + 官方 MCP stdio 联调覆盖授权界面、关闭网页后的访问、服务停止后的隐藏自启动、MCP断开后的独立后台存活、网页未登录隔离、撤销后拒绝访问、隐藏启动器的中文 / 空格路径及正常退出。所有验证使用临时虚构账本，未授权或修改真实账本。

## 14. Windows 登录后自动准备账本服务

如果希望登录 Windows 后即使不打开网页，账本服务也已在后台运行，请在“安全与智能体 → 本机后台自动解锁”先完成本机授权，再勾选“Windows 登录后自动启动后台账本”。这会为当前 Windows 用户注册一个登录触发任务，在用户登录后隐藏启动本地服务并解锁已授权账本。启动项不含明文密码或 MCP 令牌，仍由该 Windows 用户的 DPAPI 授权文件解锁。无需管理员权限。退出 Windows 用户或关机后，当前服务进程会结束，下次登录再启动。

Workbuddy 的 MCP 配置仍需有效，并且 Workbuddy 本身需要运行，才能响应你的消息或它自己的自动化安排。登录启动项负责准备本地账本服务，不会替 Workbuddy 新建自动化任务。当前任务只在 Windows 用户登录后运行，不支持停留在登录界面时无人登录解锁。

取消登录自动启动：取消该勾选。它会移除 Windows 登录任务，但保留本机后台授权，之后 Workbuddy 首次调用仍可按需启动服务。点击“锁定”、撤销授权或修改主密码会一并移除登录任务。注册由当前 Windows 桌面会话发起，任务注册失败会显示错误，可重新尝试；不会默默提示已成功。

Workbuddy 返回 `MACHINE_ACCESS_NOT_CONFIGURED` 时，表示这台电脑尚未完成本机授权，请按第13节步骤授权。返回 `LOCAL_SERVICE_START_FAILED` 时，检查当前 Windows 登录任务是否启用，或先从启动脚本启动账本并解锁。修改代码后请重启 Workbuddy 的 MCP 连接，使它加载更新后的诊断信息。生成新的 MCP 配置会轮换令牌，需用新配置替换 Workbuddy 中的旧配置。
