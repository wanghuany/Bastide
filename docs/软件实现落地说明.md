# 软件实现落地说明

开发依据为 `软件实现.md` 第 1594 行起最后一轮想法：仅电脑本地使用、数据加密、Agent 通过接口记账、Python 在本地做分析、软件直观看数据；语音识别与手机端不纳入当前范围。

## 代码放在哪里

选择直接扩展 **`PersonalLedger/Bastide`**，没有新建第三套记账项目。

- `yuan1/moneymanagerex` 是 C++/wxWidgets 桌面程序，已有复杂桌面功能和数据库加密，但不是 Python API 架构。为了接 Workbuddy 而再维护独立明文分析副本，不符合需求。
- `PersonalLedger/Bastide` 已有 Python/FastAPI、SQLAlchemy、账户/分类/交易、整数金额和余额缓存，可直接复用。原版交易接口偏向导入后的查询和分类修改，个人模式补齐了手工新增、完整修改、删除和转账。
- 在原仓库内增加独立的个人模式入口，复用原 ORM/余额函数/迁移，同时保留原版 Flutter 应用。个人模式不使用原版明文数据文件。
- 没有把 MMEX 的 GPL C++ 加密代码混进 Python 项目；MMEX 支持通过兼容 CSV 迁移，避免混用两种不兼容的加密数据库。

## 现在怎么使用

双击 `PersonalLedger/启动个人账本.cmd`。默认会打开本机 `http://127.0.0.1:8899`。

首次创建时由你设置主密码并保存恢复密钥；开发过程中没有创建真实账本、预设主密码或替你配置真实的 Workbuddy 令牌。

完整使用说明在 **`PersonalLedger/docs/personal.zh-CN.md`**，包括启动、接口、Workbuddy MCP 配置、CSV 导入、加密备份和 Python 分析。

## 本机授权与 Workbuddy 后台访问（2026-11-20）

新增显式主密码二次确认的本机后台授权，以当前 Windows 用户 DPAPI 保存受保护凭据到本机 LOCALAPPDATA，账本和 MCP 配置不包含该授权文件。MCP 在本地服务不可达且本机已授权时，通过本机 Windows 进程提供程序隐藏启动独立的 pythonw 服务，避免 MCP 重连 / 断开连带结束后台服务。生成的 MCP 配置增加明确的账本路径。已授权时启动器隐藏运行，重复启动会复用现有本地服务。

后台自动解锁不颁发网页会话，网页查看仍需主密码；授权期间有意停用闲置自动锁定与关闭网页退出，普通模式继续沿用原规则。新增授权状态、授权、撤销和退出接口，均受桌面会话保护；锁定、撤销和修改密码会删除本机授权，撤销立即锁定并拒绝 Agent 请求。授权写盘失败保留原网页会话；损坏凭据启动失败时保持锁定。用户需在真实账本界面自行首次授权，开发过程未读取真实密码、未替真实账本授权。

本机授权开启后，多设备同步前需主动退出后台服务。源码修改仍保留本地，未自动提交或上传。

本机后台授权设置中新增独立的“Windows 登录后自动启动后台账本”选项，默认不安装登录任务。当前用户明确启用后，使用 Windows Task Scheduler 的 AtLogOn 触发器及现有 pythonw 隐藏后台模式启动指定加密账本。取消选项、锁定、撤销授权和修改密码均移除该任务。注册失败会经由受桌面会话保护的接口返回错误。MCP 首次调用的按需启动能力继续保留。
