# PersonalLedger 仓库使用说明

源码仓库根目录为 `D:\VScode_TRAE\A_Bill\PersonalLedger`，GitHub 远程地址仍为 `git@github.com:wanghuany/Bastide.git`，分支为 `main`。本地目录改名不会改变提交历史或远程地址。

## 启动

双击仓库根目录的 `启动个人账本.cmd`。浏览器地址为 `http://127.0.0.1:8899`。首次设置密码，离线保存恢复密钥，保留服务终端。

## 上传和拉取

```powershell
cd D:\VScode_TRAE\A_Bill\PersonalLedger
git status
git add -A
git diff --cached
git commit -m "feat(personal): describe the change"
git push origin main
```

拉取前先提交本地修改，执行 `git pull --ff-only origin main`；分支分叉时先处理冲突，不强制覆盖。请在本仓库内操作，上一级 A_Bill 的 .git 不用于上传软件。

## 新电脑准备

安装 uv，在仓库 backend 目录运行 `uv sync --locked --extra personal`，然后运行启动脚本。Python 版本要求 3.14 及以上。依赖由 pyproject.toml、uv.lock 和 .python-version 记录。

当前电脑的 `.tools/python` 与 `backend/.venv` 为运行环境，不上传 Git；本机还在使用它们时不能直接删除。.cache 是可清理缓存。

## 账本与同步

将 personal.local.example.json 复制为 personal.local.json，配置 vault_path 为本机账本绝对路径。personal.local.json、MCP 令牌、账本和备份均不上传 Git。

本机账本已配置到 `D:\WorkBuddy\空间\智能体群\agents\bookkeeper\ledger.bfin`，首次创建后生成。使用前等待坚果云同步完成，退出软件并同步完成后再换电脑，禁止并发编辑。恢复密钥不得与账本备份存于同一个同步目录。
